# Calculadora Científica Moderna em Python

Uma calculadora científica completa desenvolvida em **Python** com interface gráfica moderna, cantos arredondados, funções trigonométricas, logaritmos, exponenciação e modo terminal.

---

## 🚀 Como Executar no seu Computador

### 1. Pré-requisitos
Certifique-se de ter o Python 3.8+ instalado.

### 2. Instalação da Interface Gráfica Moderna (CustomTkinter)
```bash
pip install customtkinter
```

### 3. Executar a Calculadora
```bash
python calculadora.py
```
*(No Linux / macOS use `python3 calculadora.py`)*

Se executado em um ambiente com interface gráfica (Windows, Mac ou Linux desktop), a janela moderna com cantos arredondados será aberta automaticamente. Em ambientes headless/servidor, o modo terminal científico interativo entra em ação automaticamente!

---

## 🧮 Recursos Matemáticos em Python

- **Trigonometria Completa**:
  - `sin`, `cos`, `tan`
  - Inversas: `asin` ($\sin^{-1}$), `acos` ($\cos^{-1}$), `atan` ($\tan^{-1}$)
  - Hiperbólicas: `sinh`, `cosh`, `tanh`
  - Modos de ângulo: **DEG** (Graus) e **RAD** (Radianos)

- **Logaritmos**:
  - `ln(x)` - Logaritmo natural (base $e$)
  - `log10(x)` - Logaritmo comum (base 10)
  - `log2(x)` - Logaritmo binário (base 2)

- **Exponenciação e Raízes**:
  - $x^y$ (`**`) - Potência arbitrária
  - $x^2$, $x^3$
  - $e^x$, $10^x$
  - $\sqrt{x}$ (`sqrt`), $\sqrt[3]{x}$ (`cbrt`)

- **Operações e Constantes**:
  - Fatorial $x!$ (`fact`)
  - Inverso $1/x$
  - Módulo $|x|$ (`abs`)
  - $\pi$ (`pi`), $e$, $\tau$ (`tau`), $\phi$ (`phi`)
  - Funções de Memória: $MC$, $MR$, $M+$, $M-$, $MS$
